📋 ESSENTIAL COMMANDS
--------------------

1. HELP - See all available commands
   python3 passgen.py --help

2. GENERATE PASSWORD - Create and save a new password
   python3 passgen.py generate --label <name> --length <number>
   Example: python3 passgen.py generate --label gmail --length 16

3. LIST ALL PASSWORDS - See all stored passwords
   python3 passgen.py list

4. GET PASSWORD - Retrieve a specific password
   python3 passgen.py get <label>
   Example: python3 passgen.py get gmail

5. DELETE PASSWORD - Remove a password
   python3 passgen.py delete <label>
   Example: python3 passgen.py delete gmail

6. ANALYZE PASSWORD - Check password strength
   python3 passgen.py analyze --label <label>
   Example: python3 passgen.py analyze --label gmail

7. BULK GENERATE - Create multiple passwords
   python3 passgen.py bulk --count 5 --save

🎯 TROUBLESHOOTING
-----------------
Error: "command not found"
→ Solution: Use python3 passgen.py before the command

Error: "No such file or directory"
→ Solution: Make sure you're in the passgen folder

Error: "ModuleNotFoundError"
→ Solution: Install requirements with: pip3 install -r requirements.txt

🔧 GENERATE COMMAND OPTIONS
---------------------------
--label: Name for the password (required)
--length: Password length (default: 16)
--no-symbols: Exclude symbols like []{}
--no-digits: Exclude numbers 0-9
--no-upper: Exclude uppercase letters

Examples:
python3 passgen.py generate --label bank --length 20
python3 passgen.py generate --label email --length 12 --no-symbols

💡 QUICK TIPS
-------------
• Always use python3 (not just python)
• Labels can be anything: gmail, facebook, bank, etc.
• Longer passwords (16+ characters) are stronger
• Your passwords are stored in plain text for easy access
• File permissions are set to owner-only for basic security
